# Zomato food sales analysis

## Project Overview

This project analyzes, Zomato online food sales data to understand sales performance, customer orders, restaurant performance and other key business metrics.

## Dataset

- Domain: Food Delivery / Online Food Sales
- Dataset contains order-level sales information
- Includes restaurant, location, cuisine, order amount, ratings and delivery information.

## Tool Used

- Microsoft Power BI

## Key Analysis

- Total Sales
- Total Orders
- Average Order Value
- Restaurant Performance
- City-wise Sales
- Cuisine Analysis
- Order Status Analysis
- Customer Rating Analysis
- Delivery Time Analysis

## Dashboard

An interactive Power BI dashboard was created to visualize the major KPIs and business insights from the dataset.
