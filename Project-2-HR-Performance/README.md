# HR Employee Performance Analysis

## Project Overview

This project analyzes employee performance, attendance, productivity, training, and promotion eligibility to identify workforce trends and performance patterns.

## Dataset

- Domain: Human Resources
- Records: 5,000 employees
- Columns: 12+ employee and performance-related attributes

## Tools Used

- Microsoft Excel
- Tableau

## Data Cleaning

The dataset was cleaned and prepared using Microsoft Excel. This included checking data quality, handling inconsistencies, formatting columns, and preparing the data for visualization.

## Key Analysis

- Employee Performance
- Attendance Analysis
- KPI Score Analysis
- Department-wise Performance
- Job Role Analysis
- Promotion Eligibility
- Peer Rating
- Task Completion
- Training Hours
- Work Hours Logged

## Dashboard

An interactive Tableau dashboard was created to provide insights into employee performance, attendance, productivity, and promotion eligibility.
