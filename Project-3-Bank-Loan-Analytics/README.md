# Bank Loan Performance Analysis

##  Project Overview

This project analyzes a bank loan performance dataset containing 50,000 customer records to identify loan trends, customer credit profiles, loan performance, and key factors affecting loan outcomes.

The project follows a complete data analytics workflow using Excel, SQL, and Power BI.

---

##  Dataset

- **Domain:** Banking / Financial Analytics
- **Records:** 50,000
- **Columns:** 14

### Key Columns

- Customer ID
- Age
- Occupation Status
- Years Employed
- Annual Income
- Credit Score
- Credit History Years
- Assets Value
- Current Debt
- Loan Type
- Loan Purpose
- Loan Amount
- Interest Rate
- Loan Status

---

##  Tools Used

- **Microsoft Excel** – Data Cleaning
- **MySQL** – Data Analysis and Business Queries
- **Power BI** – Interactive Dashboard and Visualization

---

##  Data Cleaning – Excel

The raw dataset was cleaned and prepared using Microsoft Excel.

The cleaning process included:

- Checking for missing values
- Identifying duplicate records
- Correcting data types
- Standardizing categorical values
- Checking numerical values
- Validating loan and customer information
- Preparing the final dataset for SQL analysis and Power BI

---

##  SQL Analysis

MySQL was used to perform business-oriented analysis on the cleaned dataset.

### Key Business Questions

- What is the total number of customers?
- What is the total loan amount?
- What is the average loan amount?
- What is the average interest rate?
- What is the average credit score?
- What is the loan approval and rejection distribution?
- Which loan types have the highest loan amounts?
- Which loan purposes are most common?
- How does credit score relate to loan performance?
- Which age groups have higher loan amounts?
- How does income relate to loan amount?
- Which customers have higher debt levels?

The SQL queries are included in this repository.
