# DATA-ANALYTICS-PROJECTS 
Data Analytics portfolio projects using Excel, SQL, Power BI and Tableau.

##  About This Repository

Welcome to my Data Analytics portfolio.

This repository contains three practical data analytics projects developed using real-world business datasets. These projects demonstrate my ability to clean, analyze, visualize, and interpret data to generate meaningful business insights.

The projects cover different business domains, including **Food Delivery, Human Resources, and Banking**, allowing me to apply data analytics techniques across different types of business problems.
